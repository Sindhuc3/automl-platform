# AutoML Platform

MCA 16-credit Academic AutoML Web Application.

## Module 1

Dataset Loading, Validation and Initial Inspection.

### Supported formats

- CSV
- XLSX

### Module 1 performs

- File validation
- Encoding fallback
- Delimiter detection
- Malformed row detection
- Structural validation
- Column name cleaning
- Missing value analysis
- Duplicate row analysis
- Constant column detection
- Unique value analysis
- Data type detection
- ID candidate detection
- Descriptive statistics
- Dataset preview
- Unified Quality Report

### Technology Stack

Backend:
- Python
- FastAPI
- Pandas
- NumPy
- MongoDB

Frontend:
- React
- Vite
- React Router
- Axios

Storage:
- Local filesystem for uploaded datasets
- MongoDB for dataset metadata and quality reports
